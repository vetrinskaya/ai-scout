# ИИ-скаут по маркетингу и рекламе

[English version](README.en.md)

Агент, который раз в неделю находит новинки в ИИ и рекламе и приносит 3–5 находок, которые стоят времени фаундера и маркетинговой команды:

- **ИИ-инструменты:** креативы, аналитика, тестирование;
- **рекламные платформы:** Meta, Google, TikTok, Apple, AppsFlyer;
- **агенты и модели:** новые модели, MCP, кейсы автоматизации.

Каждую находку скаут сверяет с первоисточником: сайтом компании, changelog, репозиторием. Поисковые сводки регулярно пересказывают продукты, которых нет, поэтому в конце отчёта есть блок «Не прошло проверку».

## Для кого

Для фаундеров и маркетинговых команд, которым некогда следить за всеми релизами в ИИ и рекламе. Заточен под B2C с платным привлечением: мобильные приложения, финтех, e-com. Если у вас другой продукт, опишите его в блоке «КОНТЕКСТ», и скаут перестроит отбор.

## Зачем я его сделала

Для себя. Новинок в ИИ и рекламе выходит столько, что на чтение уходила бы половина недели. А поисковые сводки уверенно пересказывают продукты, которых нет: однажды выдача дружно описывала видеопродукт Meta с ценой и функциями, а его не существовало. Мне нужен был фильтр, который приносит немного, но проверенного, и сразу пишет, что с этим делать.

Я пользуюсь им сама. Здесь его версия для вас: без моего контекста, с местом под ваш.

[Аня Ветринская](https://vetrinskaya.com), growth co-founder

## Как запустить (3 минуты)

Подойдёт любой ИИ-ассистент, который умеет искать в интернете и запускать задачи по расписанию: ChatGPT, Gemini, Perplexity, Claude. Скаут написан обычным текстом, без кода, поэтому не привязан к одному сервису.

1. Откройте [`SKILL.md`](SKILL.md) и скопируйте весь текст.
2. Заполните блок «КОНТЕКСТ»: продукт, рынки, каналы, команда, что сейчас важнее всего. Чем точнее, тем меньше шума в отчёте.
3. Вставьте текст в чат с ассистентом и допишите:
   > Выполняй эту инструкцию каждый понедельник в 9:00.
4. Попросите запустить один раз сразу, чтобы посмотреть первый отчёт.

Где это настраивается:

- **ChatGPT:** Tasks. Отчёт придёт уведомлением.
- **Gemini:** Scheduled actions.
- **Perplexity:** Tasks. Поиск у Perplexity сильный, для скаута это плюс.
- **Claude:** задачи по расписанию в десктоп-приложении, подробнее ниже.

Обычно для задач по расписанию нужна платная подписка сервиса. Сама я пользуюсь скаутом в Claude, там он проверен лучше всего.

## Если у вас Claude

В [Claude](https://claude.ai/download) копировать текст не нужно, можно отдать файл целиком:

1. Скачайте [`SKILL.md`](SKILL.md) и заполните блок «КОНТЕКСТ».
2. Откройте Claude, приложите файл и напишите:
   > Создай из этого файла задачу по расписанию: каждый понедельник в 9:00.
3. Попросите запустить задачу один раз сразу.

Отчёт появится в истории запусков задачи. Нужна подписка Pro или выше и десктоп-приложение (Cowork или Claude Code) либо Claude Code в терминале.

## Если вы собираете автоматизации сами

В n8n или Make скаут ставится цепочкой «расписание → модель с веб-поиском → Telegram или почта». Текст `SKILL.md` идёт в инструкцию модели, шаг 5 из него уберите: доставку делает сама цепочка.

## Как настроить под себя

- **Темы и источники** правятся в шагах 1–2 файла `SKILL.md`.
- **Ритм.** Можно запускать скаута каждый день, тогда в шаге 1 замените «7 дней» на «1–2 дня».
- **Язык.** Хотите отчёт на английском, допишите это в блок «КОНТЕКСТ».

## Отчёт в Telegram (по желанию)

Этот раздел для тех, у кого ассистент выполняет команды на вашем компьютере: Claude Code в приложении или в терминале. В ChatGPT, Gemini и Perplexity он не нужен: они работают на своих серверах, отчёт приходит их уведомлением. Не вставляйте туда токен бота: отправить сообщение они не смогут, а токен останется в истории чата.

Токен бота это пароль. Он хранится в связке ключей macOS (Keychain), а не в файлах. Все команды ниже вводятся в приложении «Терминал».

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Сохраните токен в связке ключей. Команда дважды попросит вставить токен, на экране он не появится:
   ```bash
   security add-generic-password -a "$USER" -s ai-scout-tg-token -w
   ```
3. Напишите своему боту любое сообщение в Telegram. Затем узнайте номер чата (chat id):
   ```bash
   T=$(security find-generic-password -s ai-scout-tg-token -w) && curl -s "https://api.telegram.org/bot${T}/getUpdates" | grep -o '"chat":{"id":[0-9-]*' | head -1
   ```
   В ответе будет строка вида `"chat":{"id":123456789`. Число в конце и есть chat id.
4. Сохраните chat id тем же способом, под другим именем:
   ```bash
   security add-generic-password -a "$USER" -s ai-scout-tg-chat -w
   ```

Готово. При следующем запуске скаут сам возьмёт токен из связки ключей и пришлёт отчёт. При первом обращении macOS может спросить разрешение на доступ: запустите скаута один раз вручную и нажмите «Разрешать всегда», иначе запуск по расписанию остановится на этом окне.

Не вставляйте токен в `SKILL.md`, в чат с ассистентом и не выкладывайте его в репозиторий.

**Windows и Linux.** Связки ключей там нет. Задайте переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` средствами системы, скаут подхватит их. В файлы проекта токен не кладите.
